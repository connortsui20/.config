# Agent Instructions

- Never use the em dash "—". Try to use commas, colons, semi-colons, and parenthesis instead.
- When writing commit messages and PR descriptions, NEVER auto-add your agent name as co-author.
- When writing lots of text (for example, markdown files for docs or even agent plans), make sure to simplify prose and make everything easy to read and understand. Use simple english.
- When making technical decisions, do not give any weight to development cost with respect to time. Instead, prefer quality, simplicity, ease of understanding, robustness, scalability, and long term maintainability.
- Always notify the user if something unexpected comes up during development that has non-trivial solutions with different tradeoffs.
- Always review and ensure that all changes (code, comments, and docs) are of the highest quality. Use skills that ensure code style and architecture are sound during review.
